# Bookmark URL Follower

**監視するブックマークを開いてリダイレクトされたら、ブックマークの URL を転送先に自動で書き換える**
Chrome 拡張 (MV3)。ドメインがよく変わるサイトをブックマークしていても、一度開くだけで新しい URL に追従します。

## 主な機能

- 設定画面(ツールバーのアイコンをクリック)に、ブラウザのブックマークバーと同じ形のバーが出ます。
  ブックマークを押すと監視、もう一度押すと解除で、監視中のものはハイライトされます。フォルダはメニューで開き、
  「このフォルダをすべて選択」もできます。選択は ↶ ↷(⌘Z / ⇧⌘Z)で元に戻せます
- バーの下に監視中のブックマークの一覧が出て、× で外せます
- 監視はブックマークの ID で覚えるので、URL が書き換わった後もそのまま追い続けます
- サーバのリダイレクト(301/302 など)、JavaScript による転送、meta refresh のどれにも追従します
- 書き換えたら、そのページの右下にトーストで知らせます。トーストの「元に戻す」で元の URL に戻せます
  (トーストを出せないページでは OS の通知になります)
- 書き換える条件を、監視中の一覧の各行の右端にあるボタンでブックマークごとに選べます
  - **[ドメイン]**(既定): ドメインが変わったときだけ。同じサイト内のログイン画面などへの転送では書き換えません
  - **[パス]**: パスや `#` 以降を含め、URL が少しでも変わったら。ページの JS による URL の書き換え
    (`history.replaceState` など)も対象
- 更新履歴をブックマークごとに 5 世代まで残し、設定画面からどの世代でも元に戻せます
- 監視中のブックマークを削除すると、監視と履歴からも消えます

## できないこと

- 旧ドメインが転送せずに消えた場合は、転送先が分からないので書き換えられません
- 定期的なチェックはしません。ブックマークを開いたときだけ動きます

## 権限について

- `<all_urls>` は、転送先のページにトーストを出すためだけに使います。ページの内容は読みません
- 監視リストと履歴は `chrome.storage.local` に保存します。ブックマークの ID は端末ごとに違うので、同期しません

## インストール

1. このリポジトリを clone する
2. `chrome://extensions` で「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選ぶ

## テスト

```sh
npm install
npm test
```

Brave Browser Nightly を背面で起動し、ローカルの HTTP サーバでリダイレクトさせて書き換えを確かめます。

## 手で試す(デモサーバ)

```sh
npm run demo
```

http://localhost:18790/ に、開くたびにドメインやパスが変わるページの一覧が出ます。リンクをブックマークバーへドラッグして監視すると、
トーストや書き換えの挙動をそのまま確かめられます。ドメインの変化には `v1.localhost`, `v2.localhost` … を使います
(Chrome は `*.localhost` を自分の PC に向けるので、hosts の設定は要りません)。
